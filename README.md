# ちいかわ おせわルーム

**遊ぶ → https://rk3263.github.io/hoppe-room/**

なでる・つつく・好きな部位をつまむだけの、小さなお世話ゲーム。
何度も引っぱると少しずつ顔が戻らなくなります。仕様です。

## 操作

- スマホ：耳・顔・手足など好きな場所を指でつまんで、そのまま上下左右に動かす。
- PC：好きな場所をマウスでドラッグ。
- 頭をなでる、体をつつく。下のボタンからも操作できます。
- 「はじめから」で顔とカウントが元に戻ります。再読み込みでもリセット。
- なでると笑顔、つつくとびっくり、引っぱると困り顔。離すと震えながら戻ろうとします。
- 頭の上を小さく往復してなでることもできます。大きく動かすと頭も伸びます。
- 音は最初の操作から鳴ります。右上の「音 OFF」で消せます。
- キーボード：キャラクターにフォーカスして ← / → でほっぺ、↑ でなでる、Space でつつく。

## 動作

ビルド不要の静的サイト。WebGL対応のSafari / Chrome / Edge / Firefox向け。
`index.html` と同じ階層に `style.css`、`game.js`、`physics.mjs`、`reactions.mjs`、画像3枚を置いてHTTPサーバーで配信します。
GitHub Pagesは `main` ブランチのルートから配信します。
外部ライブラリー、アクセス解析、広告、課金、ログインはありません。
